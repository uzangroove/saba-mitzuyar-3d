# סבא מצויר — משחק הרפתקה תלת־ממדי

פרויקט תלת־ממדי משפחתי של סבא שמעון ושליו, שבו יוצאים להציל את סבתא רבקה מהמפלצות המחזיקות אותה בטירה. המשחק מיועד לדפדפן ולטאבלט, בנוי ב־Three.js ומשתמש ב־Rapier לפיזיקה ולהתנגשויות.

> מצב נוכחי: **גרסה 15 — Vertical Prototype**. קיימת תשתית עובדת ומספר שלבי בדיקה, אך עדיין אין 100 שלבים או קמפיין מלא.

## אתר פעיל

https://saba-mitzuyar-3d-lab.sabashimon.chatgpt.site

## מה קיים בגרסה 15

- עולם ארץ ובו שלושה אזורים שונים.
- עולם חלל עם ריחוף חופשי בין אסטרואידים.
- עולם מצולות גדול עם שישה אזורים ושחייה תלת־ממדית.
- שלב ראשון בעולם היצירה והדמיון.
- מצלמות גוף ראשון וגוף שלישי.
- בקרת מגע מותאמת ל־Samsung Galaxy Tab S6.
- מכחול, ירי צבע, גשר, קפיצה, ריצה וכפתור קסם.
- מודלי GLB מקוריים של סבא, שליו, הטירה והמפלצות.
- פיזיקה תלת־ממדית וכלל שלפיו גוף בעל נפח הוא מוצק כברירת מחדל.
- בדיקות אוטומטיות לתנועה, עולמות ופיזיקה.

## מבנה המאגר

| נתיב | תוכן |
|---|---|
| `dist/` | המשחק המוכן להרצה בדפדפן, קוד, דפים ונכסי Runtime |
| `dist/assets/` | מודלי GLB ואייקוני הפעולה שבשימוש בגרסה 15 |
| `dist/vendor/` | ספריות Runtime מקומיות של Three.js ו־Rapier |
| `tests/` | בדיקות אוטומטיות לתנועה, עולמות ופיזיקה |
| `scripts/` | כלי הכנה ואופטימיזציה לדמויות |
| `docs/` | מסמך המסירה המלא והנחיות להמשך |
| `meshy_output/` | תיעוד פיילוט Meshy ההיסטורי והמושהה; אין להפעיל משימות חדשות ללא אישור |
| `.openai/hosting.json` | הגדרת הפרסום של האתר הקיים |

## הפעלה מקומית

יש להגיש את תיקיית `dist` באמצעות שרת HTTP מקומי, ולא לפתוח את קובצי ה־HTML ישירות:

```bash
python -m http.server 8080 --directory dist
```

לאחר מכן פותחים בדפדפן:

```text
http://localhost:8080
```

## בדיקות

נדרשת סביבת Node.js. התקנת תלות הבדיקות והרצת כל הבדיקות:

```bash
npm install
npm test
```

1. אין ליצור פרויקט חלופי או לחזור לגרסת דו־ממד.
2. שומרים על זהות סבא שמעון, שליו וסבתא רבקה ועל מודלי המקור.
3. עריכות ואופטימיזציה נעשות בעותקי עבודה.
4. אין לבצע פעולת Meshy, Rig, Animation או שירות בתשלום ללא אישור מפורש חדש.
5. לאחר כל שינוי מריצים `npm test`, בודקים ידנית ומבצעים commit ברור.
6. אין לשנות את אתר הפרסום או הרשאותיו ללא אישור מפורש.
